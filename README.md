# Chilanga Municipal Council Dataset – CSC 4792 (2025/26)

##Overview
This dataset was created for the **Data Mining and Warehousing course (CSC 4792)**.  
It focuses on **Chilanga Municipal Council**, assigned to our group.  
The goal is to collect, clean, and structure council information into machine‑readable formats for academic research, transparency, and governance analytics.

##Files Included
- `db-unza26-csc4792-chilanga_links.csv` → navigation links scraped from the council website  
- `db-unza26-csc4792-chilanga_cleaned_headings.csv` → structured headings extracted from web pages  
- `db-unza26-csc4792-chilanga_council_services.csv` → list of council services (business levy, health permits, fire certificates, licences)  
- `db-unza26-csc4792-chilanga_cdf_projects.csv` → sample CDF projects with ward, budget, and status fields  
- `db-unza26-csc4792-chilanga_population_and_wards.csv` → ward names and population figures  
- `db-unza26-csc4792-chilanga.ipynb` → Jupyter Notebook used for scraping and cleaning

## Tools & Methods
- Python libraries: `requests`, `BeautifulSoup`, `pandas`  
- Manual data entry for services, projects, and wards  
- Cleaning: duplicate removal, whitespace stripping, standardized delimiters (`|`)
